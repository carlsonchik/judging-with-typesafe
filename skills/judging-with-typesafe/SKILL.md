# Суждения через TypeSafe Jev

Jev — модель «System One»: не генерирует текст, а отвечает на **типизированный вопрос** о переданном
состоянии. Возвращает числа и распределения, по которым код ветвится. Это делает его пригодным там,
где нужен **воспроизводимый вердикт по критерию**, а не рассуждение.

Проверено 17.09.2026 на живом API.

## Зачем это вместо обычной модели

| | Jev | обычная LLM |
|---|---|---|
| что возвращает | число и распределение | текст, который надо интерпретировать |
| воспроизводимость | **разброс 0.004–0.014** на 8 прогонах | заметно выше, зависит от формулировки промпта |
| стоимость | ~306 токенов вход, 20 выход | тысячи токенов |
| скорость | ~2 с на запрос | десятки секунд |
| честность незнания | «0.5» вместо уверенного текста | склонна звучать уверенно |
| проверка фактов | **не умеет** (выдуманный источник получал 0.80 против 0.87 у настоящего) | тоже не умеет |

## Установка и доступ

Ключ берётся из `TYPESAFE_API_KEY`. Скрипты читают её через `zsh -lic`, поэтому работают даже
когда приложение запущено со старым окружением (переменная попадает только в новые процессы).

```bash
python3 scripts/typesafe.py noul   "состояние" "вопрос"                    # вероятность «да» 0..1
python3 scripts/typesafe.py choice "состояние" "вопрос" -o а б в           # выбор варианта + вероятности
python3 scripts/typesafe.py score  "состояние" "вопрос" -o низко средне высоко
```

Скан документа по абзацам:

```bash
python3 scripts/scan_text.py статья.md --mode argument --min-len 300
# режимы: argument (есть утверждение с основаниями), claim (требует проверки), source (указан источник)
# результат рядом с файлом: <имя>-скан-argument.json
```

## Три примитива

- **noul** — вероятность «да» для утверждения. **0.5 значит неопределённость, а не «средне».** На бессмысленном
  вопросе даёт низкое значение (0.17), на вопросе без данных о предмете — около 0.5 (0.43). Это правильное поведение.
- **choice** — выбор одного из вариантов. Возвращает `choice`, `probabilities`, `confidence`.
- **score** — позиция на упорядоченной шкале. **`criteria` обязан быть СПИСКОМ**, не объектом: на объект API
  отвечает ошибкой валидации.

`confidence` у choice/score — это **концентрация распределения**, а не «уверенность в правильности».
Проверено: при вероятностях 0.5/0.5 уверенность падает до 0.25, при явном лидере — 1.0. Это живая величина.

## Как формулировать вопрос

Один вопрос меряет **одно**. Проверено на трёх типах фрагментов:

| Фрагмент | «есть основания?» | «доказывает или называет?» | «заявляет больше, чем обосновывает?» |
|---|---|---|---|
| перечисление полей | 0.26 | 0.31 | 0.53 |
| сильный аргумент с контрпримером | **0.84** | 0.59 | **0.88** |
| признание открытости вопроса | 0.23 | 0.33 | 0.6 |

Вывод: вопрос «есть ли утверждение с основаниями» даёт разрыв в три раза и честно понижает
перечисления и постановки вопросов. Вопрос про «переобещание» размывает границу — он тянет
за собой оценку, которой в тексте нет. **Берите первый.**

## Как интерпретировать (важнее самих чисел)

- **Низкий балл ≠ плохой текст.** Он значит «этот фрагмент не является утверждением с основаниями»:
  список, постановка вопроса, признание открытости. Такой абзац оценивается другим вопросом.
- **Смысл имеют сравнения внутри одного корпуса, а не абсолютные значения.** Порог 0.55 откалиброван
  на двух статьях одного автора; для другого материала его надо пересчитать.
- **Модель следует за контекстом, а не за своей позицией.** На политически спорном материале с обеими
  позициями в состоянии она уходит в неопределённость (0.41–0.58), а на проверяемом факте отвечает
  твёрдо (0.06 по признанию, которое зафиксировано документом). Но если состояние одностороннее —
  число будет односторонним: **она не спорит с контекстом и не добавляет того, чего в нём нет**.
- **Двойной счёт с моделью-агентом:** Jev оценивает предъявленное, а не мир. Не перекладывать на него
  проверку ссылок, фактов и институциональную подотчётность.

- Калибровка на 8 случаях с известным ответом: 6 из 8 в пределах 0.15 от ожидания, на симметричных

  подняла оценку следования вывода с 0.504 до 0.546 (разброс внутри случая — 0.009–0.014, то есть
  разница значима).
